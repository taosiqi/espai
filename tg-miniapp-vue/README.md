# TG Mini App Vue

Vue + Vite Telegram Mini App demo.

## Run

```bash
npm install
npm run dev
```

If npm is unavailable, use the bundled static server:

```bash
node server.mjs
```

Then open:

```text
http://192.168.1.6:7456/
```

## Features

- Auto `ready`, `expand`, `requestFullscreen`, `lockOrientation`
- Open Telegram internal browser
- Request external browser
- System share
- Telegram share
- Download a base64 PNG image
